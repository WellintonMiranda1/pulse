## Base demonstrativa integrada

O Pulse já inicia com uma base fictícia completa para apresentação:

- 3 vendedores
- 30 clientes fictícios
- 80 vendas distribuídas entre abril e outubro de 2026
- clientes em diversos estados brasileiros
- metas mensais por vendedor
- oportunidades e leads
- clientes ativos, churn e perdidos
- dados suficientes para ranking, mapa, gráficos e análise comercial

Na primeira abertura desta versão, a base v2.6 substitui automaticamente seeds antigos do navegador. Depois disso, as alterações realizadas durante a demonstração continuam salvas normalmente no localStorage daquele navegador.

> Esta versão é uma demonstração local baseada em localStorage. Autenticação e isolamento real por empresa exigirão backend/banco de dados na versão comercial.
